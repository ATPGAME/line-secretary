# Next.js 16 Security Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the LINE secretary application to a zero-known-vulnerability Next.js 16 dependency tree without changing its behavior or data model.

**Architecture:** Keep the existing App Router, LINE webhook, scheduled jobs, PostgreSQL schema, and dashboard unchanged. Replace only the framework/runtime dependency tree, then use local, Preview, and Production gates so no unverified build reaches the live LINE OA.

**Tech Stack:** Next.js 16.3.3, React 19.2.8, Node.js 22+/Vercel Node.js 24, PostgreSQL via `pg`, PGlite SQL tests, Vercel.
