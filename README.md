# เลขาส่วนตัวใน LINE OA — ต้นแบบสำเร็จรูป

| ทำอะไรได้ | ลองพิมพ์/ส่งใน LINE |
|---|---|
| จำข้อมูลให้ | "จดไว้ รหัส wifi บ้าน 12345678" → อาทิตย์หน้าถาม "รหัส wifi อะไรนะ" ก็ตอบได้ |
| งานที่ต้องทำ | "เตือนส่งงานลูกค้าพรุ่งนี้ 10 โมง" · "มีอะไรต้องทำบ้าง" · "ปิดงาน 2" |
| **ส่งสลิป → บันทึกรายจ่าย** | ส่งรูปสลิปเข้าไปเฉย ๆ → "บันทึกแล้ว 120 บาท · เดือนนี้ใช้ไป 3,450" |
| **พูดแทนพิมพ์** | อัดเสียงส่ง "นัดหมอศุกร์บ่ายสอง" → ถอดเสียงแล้วจดให้เลย |
| รวมยอดรายจ่าย | "เดือนนี้ใช้เงินไปเท่าไหร่" |
| **สรุปกลุ่มสด** | พิมพ์ในกลุ่มว่า "เลขา สรุปให้หน่อย" → สรุป + งานที่ค้างทันที |
| **สรุปกลุ่มอัตโนมัติ** | 8 โมงเช้า / 6 โมงเย็น สรุปทุกกลุ่มเข้าแชทส่วนตัว |
| **คำต้องห้าม → เตือนทันที** | มีคนพิมพ์ "ยกเลิก / คืนเงิน / ไม่พอใจ / ด่วน" ในกลุ่มไหนก็เด้งหาเจ้าของทันที |
| **ลูกค้าถามค้าง → เตือน** | ในกลุ่มมีคำถามแล้วเงียบเกิน 15 นาที → เตือนว่ายังไม่มีใครตอบ |
| **สรุปออเดอร์** | กลุ่มสั่งของ → สกัดออเดอร์ + รวมยอดแนบมากับรายงาน |

## ใช้ 4 อย่าง (ค่าใช้จ่ายจริง ~$5/เดือน)

| ตัว | หน้าที่ | ราคา |
|---|---|---|
| **LINE OA** | หน้าร้าน — ที่คนพิมพ์คุย | ฟรี (push 300 ข้อความ/เดือน · ตอบแชทไม่นับ) |
| **OpenRouter** | สมอง — คิด ตัดสินใจใช้เครื่องมือ สรุปกลุ่ม | จ่ายตามใช้ หลักสตางค์ต่อข้อความ |
| **Vercel** | หู — รับ webhook + หน้า dashboard | ฟรี |
| **Railway** | สมองรอบเวลา — worker วนสรุปทุก 10 นาที | $5/เดือน |
| **Neon** | ความจำ — เก็บทุกอย่างถาวร ย้อนหลังได้ | ฟรี |

**กฎที่ตัดสินทั้งระบบ: หู ≠ สมอง** — webhook แค่เขียนข้อความลงฐานข้อมูลแล้วตอบ 200 ทันที ไม่เรียก AI (กลุ่มหนึ่งมี 500+ ข้อความ/วัน ถ้ายิง AI ทุกข้อความคือจ่ายค่า token ให้คำว่า "555" และช้าจน LINE ตัดการเชื่อมต่อ) แล้วให้ worker บน Railway มาสรุปเป็นรอบ

```
คนพิมพ์ในกลุ่ม → Vercel /api/line → เขียนลง Neon → ตอบ 200 (จบใน 0.3 วิ)
คนพิมพ์หาเลขาตรง ๆ (แชท 1:1 หรือขึ้นต้นว่า "เลขา") → เรียก AI ตอบทันที
ทุก 10 นาที → Railway worker เช็คว่าถึงรอบรายงานยัง → สรุป → push เข้าแชท 1:1 ของเจ้าของ
```

## ติดตั้ง — มือใหม่ทำเสร็จใน 2 ชั่วโมง

**ไม่ต้องเขียนโค้ดเอง** ให้ Claude Code ติดตั้งให้ หน้าที่เราคือสมัครบริการแล้วส่งค่าให้มัน

### 1. สมัคร 4 อย่างนี้ก่อน (ทำในเว็บ ~20 นาที)

| สมัครที่ | ได้อะไรมา | เตรียม |
|---|---|---|
| [manager.line.biz](https://manager.line.biz) | สร้าง OA + เปิด Messaging API → ได้ Channel secret | บัญชี LINE |
| [developers.line.biz](https://developers.line.biz) | Channel access token (กด Issue) | บัญชีเดียวกัน |
| [openrouter.ai](https://openrouter.ai) | API key | บัตร (เติม $5) |
| [vercel.com](https://vercel.com) | — (แค่สมัครไว้) | GitHub |
| Neon | **ไม่ต้องสมัครแยก** — กดสร้างในหน้า Vercel → Storage ตอนติดตั้ง | — |
| [railway.app](https://railway.app) *(ทำทีหลังได้)* | — | บัตร $5/เดือน |

⚠️ **ข้อที่คนพลาดเยอะสุด** — ที่ [manager.line.biz](https://manager.line.biz) → **การตั้งค่า → การตอบกลับ** → **ปิด** "ข้อความตอบกลับอัตโนมัติ" กับ "ข้อความต้อนรับ" (ถ้าไม่ปิด บอทจะเงียบเพราะโดนข้อความสำเร็จรูปแย่งตอบ)
สวิตช์ **Webhook** ในหน้าเดียวกันยังเปิดไม่ได้ตอนนี้ — ต้องมี URL ก่อน เดี๋ยว Claude พากลับมาเปิดหลัง deploy เสร็จ

### 2. เปิด Claude Code แล้ววาง prompt นี้

```
ช่วยติดตั้งเลขา LINE OA ให้หน่อย ผมไม่เคยเขียนโค้ดมาก่อน
โค้ดอยู่ที่ https://github.com/gobank01/line-secretary
โคลนมาแล้วทำตาม INSTALL.md ในโปรเจค ถามผมทีละขั้นนะ
```

Claude จะพาทำทีละขั้นแบบ wizard **10 ขั้น** — บอกให้สมัครทีละเว็บ ขอค่าทีละตัว
และ**ตรวจให้เห็น ✅ ก่อนถึงจะไปขั้นถัดไป** (ไม่ใช่ไปพังตอนจบ) ทำค้างไว้แล้วปิดแชทได้ กลับมาบอกว่า "ทำต่อ" มันจำได้ว่าถึงไหน

```
[ขั้น 5/10] ✅✅✅✅⬜⬜⬜⬜⬜⬜ — สมัคร OpenRouter
✅ ต่อ LINE OA ได้: "เลขาน้องมิ้น" (@123abcd)
```

ค่าทั้งหมดถูกเขียนลงไฟล์ `.env.local` ในเครื่องตัวเอง ไม่ถูกส่งไปไหน

### 3. ขั้นสุดท้าย Claude จะถามว่า "อยากให้บอททำหน้าที่อะไร"

ทำธุรกิจอะไร · อยากให้เรียกคุณว่าอะไร · ให้ช่วยเรื่องไหนมากที่สุด · อะไรที่ห้ามทำ
แล้วมันจะเขียน [lib/persona.js](lib/persona.js) ให้ตรงกับธุรกิจคุณ — **นี่คือขั้นที่ทำให้บอทเป็นของคุณ ไม่ใช่บอทสำเร็จรูปที่เหมือนกันทุกคน**

เปลี่ยนใจทีหลังก็บอก Claude ได้ตลอด: "แก้ persona ให้เรียกผมว่าเฮีย พูดห้วนกว่านี้" · "เพิ่มเครื่องมือจดวันเกิดลูกค้า" · "เปลี่ยนเวลารายงานเป็น 7 โมงกับ 3 ทุ่ม"

### เช็คว่าใช้ได้จริง

ทักบอทในแชทส่วนตัว:
> จดไว้หน่อย รหัส wifi บ้าน 12345678
> เตือนส่งงานลูกค้าพรุ่งนี้ 10 โมง
> มีอะไรต้องทำบ้าง

แล้วเชิญ OA เข้ากลุ่ม → บอทแนะนำตัว → 8 โมงเช้ากับ 6 โมงเย็นจะได้สรุปเข้าแชทส่วนตัว
(แก้เวลาได้ที่ตาราง `watched.report_hours`)

ดูทุกอย่างที่ `https://ชื่อโปรเจค.vercel.app/dashboard?key=DASHBOARD_KEY`

## ไฟล์ไหนทำอะไร

| ไฟล์ | หน้าที่ |
|---|---|
| [app/api/line/route.js](app/api/line/route.js) | หู — verify ลายเซ็น → เก็บข้อความ → อ่านสลิป/ถอดเสียง → เตือนคำต้องห้าม |
| [worker/index.js](worker/index.js) | สมองรอบเวลา — สรุปกลุ่ม + ออเดอร์ + SLA watcher (รันบน Railway) |
| [lib/brain.js](lib/brain.js) | เรียก OpenRouter + เครื่องมือ 6 ตัว (เพิ่มเครื่องมือใหม่ที่นี่) + สรุป/อ่านสลิป/ถอดเสียง |
| [lib/db.js](lib/db.js) | Neon — ความจำ + เก็บข้อความดิบ |
| [lib/line.js](lib/line.js) | ตรวจลายเซ็น + reply + push |
| [lib/persona.js](lib/persona.js) | **หน้าที่และบุคลิกของบอท** — แก้ไฟล์เดียวเปลี่ยนตัวตนได้ทั้งตัว |
| [lib/schema.js](lib/schema.js) | ตารางทั้งหมด — สร้างให้ตอนติดตั้ง |
| [scripts/setup.mjs](scripts/setup.mjs) | ติดตั้งอัตโนมัติ — สร้างตาราง + ตั้ง webhook + ยิงทดสอบ |
| [scripts/check.mjs](scripts/check.mjs) | ตรวจทีละบริการว่าค่าที่ใส่ใช้ได้จริง (`line` / `openrouter` / `db` / `vercel <url>` / `all`) |
| [scripts/push-env.mjs](scripts/push-env.mjs) | ส่งค่าจาก `.env.local` ขึ้น Vercel/Railway ทั้งชุด (ค่าไม่โผล่บนหน้าจอ) |

`npm test` = เช็คลายเซ็น LINE กับตรรกะ to-do (ไม่ต้องต่อเน็ต ไม่ต้องมี DB)
เปิดหน้าแรกของเว็บ = ตรวจสุขภาพ บอกเองว่าค่าไหนยังไม่ใส่ / ตารางสร้างหรือยัง

## ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ |
|---|---|
| Verify ไม่ผ่าน | ยังไม่ redeploy หลังใส่ env / URL พิมพ์ตก `/api/line` |
| บอทเงียบ ทั้งที่ทุกอย่างถูก | **ยังไม่ได้เปิดสวิตช์ Webhook** (ต้องเปิดหลังใส่ URL แล้วเท่านั้น) หรือ `LINE_CHANNEL_SECRET` ผิด (Vercel log จะเห็น 401) |
| ตอบเป็นข้อความสำเร็จรูป | ยังไม่ปิด Auto-reply messages |
| เชิญเข้ากลุ่มไม่ได้ | ยังไม่เปิด Allow bot to join group chats |
| ไม่มีรายงานเข้า | `OWNER_USER_ID` ว่าง / worker ไม่ได้รัน (ดู Railway Logs) / ยังไม่ถึงชั่วโมงใน `report_hours` |
| too many connections | ใช้ connection string ที่ไม่มี `-pooler` |

## ปรับแต่งต่อกลุ่ม (แก้ในตาราง `watched`)

```sql
-- เปลี่ยนเวลารายงาน / คำที่ให้เตือน / เวลารอตอบ / เปิดสรุปออเดอร์
update watched set report_hours = '{7,12,20}',
                   alert_words  = '{ยกเลิก,คืนเงิน,ด่วน,เจ๊ง}',
                   sla_minutes  = 30,      -- 0 = ปิด
                   track_orders = true
 where source_id = 'Cxxxxx';
```
